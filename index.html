모든 모델 · 전체 iteration 학습 기록 (TensorBoard)

위 평가 그래프와 별개로, 실제 학습 로그의 모든 iteration을 읽었습니다. 학습 보상과 독립 평가 성공률은 서로 다른 지표입니다. 각 행을 펼치면 점 그래프가 표시됩니다. 없는 지표는 해당 모델을 숨기지 않고 ‘기록 없음’으로 표시합니다.

모델별 중간점검 · Iteration 점 그래프

X축: 학습 iteration · Y축: 위에서 선택한 성능 지표. 점 하나는 저장된 평가 한 건이며, 마우스를 올리면 버전·값·원본을 볼 수 있습니다. 같은 실행도 난이도와 평가 길이가 다르면 분리합니다. 시드가 다른 점은 겹칠 수 있습니다. 누락된 중간평가는 보간하지 않습니다.

브랜치·버전 성능 비교

보고서에 기록된 지표만 표시합니다. 실행 전체 통계는 개별 체크포인트 점수가 아닙니다. 서로 다른 보상·난이도·평가 조건의 값은 직접 순위로 해석하지 마세요. 충돌·낙상·오차 지표는 보통 낮을수록 좋습니다.
